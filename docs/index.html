Как на самом деле устроена цена аренды и какие места рядом с квартирой объявление никогда не упомянет.

Сюрприз доплаты

Циан, долгая аренда, студии и 1-к в одном районе. У каждой квартиры — цена из объявления (левая точка) и полная цена в месяц (правая точка): аренда + коммуналка + комиссия / 11 месяцев. Где коммуналка не указана, она оценена медианой указанных сумм по формату, тонкий отрезок — разброс оценки p25–p75.

Каток:

Баллы — по формуле поиска (раздел 5.1 отчёта): близость 0 при ≥ 20 мин пешком, максимум — при ≤ 5 мин; место, выбранное единственным после метро, весит 0,5 (= 50 баллов из 100). Левая точка — 0 (в объявлении это место никак не названо), правая — медиана баллов среди квартир, которые и правда рядом. Минуты — пешком по OpenStreetMap, только у объявлений с точкой на доме.
