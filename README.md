# Ассистент для поиска съёмной квартиры в Петербурге

Итоговый проект курса «Квалифицированный заказчик» (ИТМО), Дарья Подакова, ноябрь 2026.
Дашборд: https://daryapodakova.github.io/rent_automatization/

## 1. Задача
Цена в объявлении не равна платежу: коммуналка, комиссия и залог разбросаны по свободному тексту или не указаны. Ассистент разбирает объявления в карточки, считает полную цену в месяц (или её диапазон) и минуты пешком до мест, важных человеку, а отправку сообщения хозяину оставляет за человеком.

## 2. Данные
Объявления из открытого Telegram-канала «Уезжаю / Остаюсь» (1 046) и поиска Циана по одному району за один месяц (285). После очистки — 715 объявлений долгой аренды (Telegram 575, Циан 140). Адреса и объекты — OpenStreetMap (© участники OSM, ODbL). Ограничения: Циан — один район и один месяц; полнота OSM не проверена.

## 3. Структура репозитория
- `docs/` — дашборд (GitHub Pages): водопад драйверов, надёжность цены, калькулятор юнит-экономики.
- `data/` — обезличенные данные: `offers_raw.csv`, `offers_clean.csv`, `cleaning_log.csv`, `agent_log.csv`, `econ_model.json`, `economics.xlsx`.
- `notebooks/` — `data_analysis.ipynb` (этапы 2–3), `agent.ipynb` (этап 5).
- `pipeline/` — схема карточки, системный промпт, сценарий n8n, оценка на эталоне.
- `collect/` — сбор и сборка: парсер Циана (координаты зон убраны), выгрузка OSM, склейка источников, сборка дашборда.

## 4. Как устроен разбор
Шаблонные поля разбирают регулярки, свободный текст — модель (DeepSeek V4.1 Flash через OpenRouter), контакты маскируются до отправки. Полную цену, диапазон и минуты считает код, а не модель. Неизвестная коммуналка — медиана по формату с диапазоном p25–p75, а не ноль.

## 5. Качество на эталоне из 200 постов
Взвешенная точность (регулярки / только модель / гибрид по полям): коммуналка 95,2 / 94,2 / 97,0%; комиссия 98,8 / 94,8 / 98,2%; срок аренды 97,6 / 96,6 / 99,4%; дата заезда 96,7 / 94,9 / 96,7%; цена 97,9 / 97,2 / 99,4%. Прогон один, 200 вызовов. Эталон размечали модели (Claude, повтор вслепую Sonnet), роль автора проставлена скриптом — это не независимая человеческая оценка. Сам эталон не публикуется: в нём тексты постов.

## 6. Агент
Python, LangChain, инструменты `parse_listing`, `search_offers`, `draft_to_owner`, `send_to_owner`; отправка останавливается кодом до решения человека. Итоговый прогон: 10 строк лога в `data/agent_log.csv`, 15 вызовов модели.

## 7. Экономика
Модель с формулами — `data/economics.xlsx`, те же формулы считает калькулятор на дашборде. База не окупается: LTV/CAC 0,98, окупаемость разработки только в оптимистичном сценарии (5,5 мес.). Конверсии и охват — допущения, проверяются пилотом.

## 8. Ограничения и приватность
Сценарий n8n не проверен на живом инстансе; агент и модель прогнаны по одному разу. Контакты, ссылки на посты и номера домов из данных удалены, станции и улицы Циана заменены метками. Сырые выгрузки и эталон в репозиторий не входят. Ключи API в `.env`, в репозитории их нет.
